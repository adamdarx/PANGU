# BBH、TOV、BNS 的物理验收

本协议补充运行完成、有限值、重启和视界寻找器检查。仅有这些软件检查，
不能标记为物理验收通过。机器可读规则为
`tst/reference/compact_physical_acceptance_v1.json`，执行器为
`tst/regression/compact_physical_acceptance.py`。

除沿用的坍缩前重子质量和视界残差门限外，下列数值是明确声明的**项目精度预算**，
不是论文给出的普适标准，也不代表原用户指定过这些阈值。
预算在 N128 生产结果完成前固定；若需要修改，新增协议版本并说明理由，
保留旧结果，不为取得通过而覆盖门限。

## 实际算例与独立依据

| 算例 | 当前物理设置 | 验收路线 |
|---|---|---|
| 双黑洞 | 等质量正碰、准圆轨道、对齐自旋三种 Bowen–York 初值 | 核对已有 PANGU/AthenaK 配对初值，比较遗留质量、自旋和复波形 |
| TOV 坍缩 | Γ=2、K=100、ρc=0.007993、vpert=-0.01、b_norm=1 | 独立 TOV ODE 验证未扰动母星，64/96/128 分辨率与已有 CFL、边界对照 |
| BNS 正碰 | Γcold=Γthermal=2、K=100、间距24、初速0；约束求解双星表 | 实际初值 ADM 质量与约束、坍缩前守恒、64/96/128 的遗留量及主导 m=0 波形收敛 |

BNS 的初始 ADM 总质量为2.6548889790689447，重子质量为2.9268335193383828；
不能用两个孤立种子星质量之和替代。它不是无穷远自由落体或准圆轨道初值，
不能直接套用不同初值论文的坍缩时间、并合时间或 m=2 相位。

独立 TOV 参考使用自适应焓变量 DOP853 积分，不调用 PANGU 或 AthenaK 的
TOV 实现。对当前未扰动母星，得到 M=1.44759418916、R_areal=5.83811274303、
Mb=1.53540811851；收紧积分容差验证误差。该参考不包括后加的磁场与速度扰动，
不能把它与扰动后的全能量预算混为一谈，也不能要求不稳定坍缩星保持恒定中心密度。

方法参考：
[AthenaK 数值相对论](https://arxiv.org/abs/2409.10383)、
[AthenaK 动力学 GRMHD/BNS](https://arxiv.org/abs/2409.10384)、
[Einstein Toolkit 的恒星与坍缩测试](https://arxiv.org/abs/1111.3344)。
这些来源支持采用守恒、独立母星解、波形和收敛检查；下表百分比由本项目声明。

## 定量门限

| 指标 | 门限与定义 |
|---|---|
| 视界寻找质量 | M_input×RMS(Θ_expansion) ≤10⁻⁴；仅是几何测量质量前置条件 |
| 外部约束 | M_ADM,0²×proper-volume RMS(H) 和 RMS(metric-contracted momentum) 各≤10⁻³ |
| 全能量收支 | 相对残差≤1%；必须计入同一渐近/受控有限世界管定义下的辐射及物质/电磁通量和截断误差 |
| 边界、时间步系统误差 | 外边界加倍、CFL减半，各自造成的晚时质量变化≤0.5% |
| TOV 母星质量、半径 | 独立 ODE 的质量差≤0.1%，**面积半径**差≤1% |
| 坍缩前重子质量漂移 | TOV≤10⁻⁵；BNS≤10⁻³，必须包含重启前完整前缀 |
| 物质坍缩遗留质量 | 三分辨率 finest Richardson 相对误差≤1%；同一晚时窗范围≤0.5% |
| 物质坍缩遗留自旋 | 当前无旋初值应有 abs(J_AH)/M_Christodoulou²≤10⁻³ |
| 坍缩检测时间 | 分辨率及视界采样间隔合成相对不确定度≤5%；不声称有普适精确坍缩时间 |
| 物质外部约束收敛 | 三分辨率观测阶≥0.8；允许激波限制的一阶，不强行指定四阶 |
| BNS 主导波形 | 三分辨率相对不确定度≤5%，受控有限提取半径差≤3% |
| BBH 双代码遗留量 | 相对质量差≤1%，无量纲自旋绝对差≤0.02 |
| BBH 双代码波形 | 主导复 M*r*Ψ4 相对 L2≤3%，峰值延迟时间差≤1 M_ADM,0 |
| BBH 非正碰相位 | 准圆/对齐自旋主导模式相位差≤0.1 rad，仅比较振幅大于峰值1%的区间 |

正碰使用同一轴/球谐约定下事先指定的非零四极模式的复 L2 与峰值时刻（当前 x 轴 BBH 用 m=2，z 轴 BNS 用 m=0）；不把接近零的实波形相位跳变当作
准圆模式的连续相位误差。所有自旋先从角动量 J 转成 χ=J/M²，不能把名为
`spin` 的有量纲数据直接当 χ。

## 区域、时间、误差预算

1. 约束检查排除掩膜与所有视界内部，不使用奇点内的全域最大值否定外部解。
   同一比较组使用相同的实际空间区域与 proper-volume 权重；现有晚时物质
   汇总可使用8<r_coordinate<30，但须先证实所有比较视界的最大坐标半径小于8。
   坐标半径、面积半径、归一化质量、切片规范必须注明。
2. 使用同一物理时间窗，报告最后可靠视界采样与输出间隔，不向目标时刻外推缺失数据。
   Richardson 使用实际有效网格距，不能把64/96/128误作固定倍数2。
   非单调、近零差或不足三档时不虚构收敛阶。
3. 波形核对模式、四标架、复数符号、质量归一化和延迟时间。若需常数时间/相位
   校准，固定在事先声明的早期窗，不逐段拟合抹去误差。剔除 junk 以及已受
   外边界反射污染的区间；有限半径影响需要单列，不能混入网格误差。
   正式相位误差使用连续 unwrap 后的相位，不能用取模到[-π,π]掩盖整周误差。
4. 重子守恒量为 ∫D d³x，其中 D 已含 sqrt(gamma)。有限体积预算应计入边界通量
   和**累计**数值恢复/大气源。若只积分视界外部，还须计入移动内边界通量。
   最后一个 RK 子步的 recovery 场不能当作整个演化的累计源。
5. 能量预算不能直接把任意切片上的局域 Eulerian 能量体积分当作精确 ADM 分解。
   缺失的辐射、源、提取误差或剩余外部物质项不得填零；此项保持待验收，
   或配置真正匹配的独立代码算例补充验证。

## 当前证据限制

历史 N32 BBH 输出使用约10⁻²的视界扩张容差，不能自动继承当前10⁻⁴几何门限。
允许对闭合场离线重求视界，不影响已运行生产任务。重启造成的诊断前缀和失败
尾段应按实际 checkpoint 边界拼接；缺失完整主信号时，晚时重叠段比较只作为预览。
已核对的旧配对初值参数一致，但 PANGU 使用四阶空间差分和 classical RK4，
AthenaK 的 `nghost=4` 对应六阶差分。不同离散方法的低分辨率差值需要收敛误差
评估，不能声称为同数值配置逐场比较；也不能仅凭此差值认定物理模型错误。

现有 TOV/BNS 的 N64、N96 完成记录只说明已完成数值演化与若干检查。
N128 尚在运行；全能量/累计源及完整收敛证据未齐，均不标记最终物理通过。

## 运行

每个测量提供 `value` 和至少一个 `{path, sha256}` 源证据，路径相对测量 JSON。
双黑洞还必须写明 `family=head_on|quasicircular|aligned_spin`。

```sh
python tst/regression/compact_physical_acceptance.py \
  --measurements measurements.json --output physical-review.json
python tst/reference/polytropic_tov_oracle.py \
  --rhoc .007993 --output tov-independent-reference.json
```

退出码0=通过、1=已有指标失败、2=证据不全待验收。任何缺少的指标、源文件或
SHA不匹配均不会被填成零误差或自动通过。完成、归档校验与物理通过分开记录。
