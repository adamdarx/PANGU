## 1. 双黑洞：一个代表算例，完整收敛与独立对照

- 保留三个 N32 历史算例的原始记录。至少选择一个代表算例，获得三档实际
  网格距下的完整并合轨迹，报告观测阶和数值不确定度。使用不等比网格距时
  按实际 h 计算；若未进入渐近收敛区或差异非单调，应说明并报告误差包络。
- 优先复用已有准圆轨道算例做收敛准备，正式网格及资源由叶块数、每卡内存、
  最小步长和短程耗时决定；尚未冻结新的生产分辨率。三档须覆盖相同物理
  AMR 区域及波区，单独增加近洞层数不等于完整波形收敛测试。
- 核对独立程序的完整物理初值、单位、ADM 归一化和提取定义后，比较复数
  rΨ4/应变、幅度和连续相位、波形峰值延迟时间、末态 Christodoulou 质量及
  χ=J/M²。近零自旋用绝对误差，不能除以近零参考量；同时给出网格、提取
  半径、视界与参考程序本身的不确定度。
- 区分共同视界首次检出时间与波形峰值时间。坐标并合时间只在切片、规范和
  时间起点匹配时直接比较；只允许事先声明的早期窗对齐，不逐段拟合消除误差。

GW150914 是可选的公开对照路线，需在现有算例补测和公开基准之间明确选择。
[AthenaK 作者教程](https://github.com/dradice/athenak-tutorial-gw150914)
与 [Einstein Toolkit 公开算例](https://einsteintoolkit.org/gallery/bbh/index.html)
提供输入依据，但两套示例的初始参数不同，同名事件不构成等价初值。
其完整生产资源也不能直接沿用到本机。先固定一套参数和参考数据，再审核映射、
资源及可比较量；禁止把旧等质量 N32 算例改名为 GW150914。

## 2. 弱场、单黑洞：把误差来源分开

- 弱场使用同一幅度、规范、时刻及范数，检查截断误差区间、时间误差、
  浮点舍入与输出精度。误差平台或随分辨率上升的导数残差需要归因；仅有
  有限值或更小网格不能声明收敛，机器精度附近不强行拟合收敛阶。
- 单黑洞报告相对解析/独立初值的初始偏差、同一初值静态视界复测的误差、
  以及固定弛豫窗之后的演化漂移。先核对初值是否本来就处于定态，识别初始
  弛豫与 junk radiation，再讨论长期质量和自旋保持。
- 对同一闭合快照改变角分辨率、球谐截断、扩张容差及初始猜测，避免将视界
  搜索误差误认为演化误差。现有 `diagnostics_only` 入口已能保持 Time、NCycle
  和独立演化变量不变，普通重启的缓存行为也已经验证。
- 性能分两类：相同硬件/卡数/MPI/精度/物理网格与输出策略下的吞吐；达到
  相同物理误差所用的总卡时。记录初值、诊断、通信、I/O 与演化的耗时，
  稳态段重复测量并给出离散程度。单 CPU 核与 GPU 的比值不能作为双代码优势。

## 3. GRMHD：直接对照和两项质量问题

先将现有 TOV/AthenaK 短程逐场对照接到稳定星及同一物理初值的坍缩测试。
比较中心/最大密度时序、频率或坍缩增长、首次可靠视界时间及采样误差、晚时
质量/自旋、重子预算。EOS、磁场、速度扰动、大气、恢复策略和实际空间分辨率
均须登记；现有短程测试脚本的存在不等于本次长跑已有可靠的独立结果。
[ET 稳定 TOV 参考](https://einsteintoolkit.org/gallery/ns/index.html)可补充独立
稳定星基准；[ET 准圆 BNS 示例](https://einsteintoolkit.org/gallery/bns/index.html)
不能直接替代当前从静止正碰、约束求解双星初值。

两项问题独立挂账，不能用“误差变小”关闭：

| 问题 | 已核实的数据 | 还需证明什么 |
|---|---|---|
| BNS 视界质量高于初始 ADM | M0=2.6548889790689447；共同晚窗160–198.12656内，N64/N96平均视界质量偏高0.07630%/0.01772% | 同态视界精度、N128与收敛误差、初值 ADM、辐射/物质和数值源的相容能量收支 |
| 成洞后重子质量漂移 | N64/N96全域末帧相对各自网格初值漂移+0.08609%/+0.08044%；坍缩前漂移较小并不能解释它 | 区分掩膜、移动内边界通量、外通量及大气/原始量恢复的累计外部源 |

这些数值来自已有完整归档与同一晚时窗，仅是问题量化，未给出原因结论。
表中 M0 使用约束初值表的 ADM 值；N128 初始场已做外部单极核对，但仍须
分别核对 N64/N96 的实际初始场，不能将一档初值精度推广到所有分辨率。
`last_stage_recovery_mass` 是阶段量，不能直接当全时段累计源。
遵守掩膜内部无需场精度验收的范围：对物理外部区域建立含移动内边界的预算，
旧全域重子漂移另列；不能把落入黑洞的外部重子减少直接记作守恒破坏。
全能量收支应使用相容的 ADM/Bondi 或受控世界管定义，不能任意把局域 Eulerian
能量积分当作 ADM 分解，也不能将漏掉的辐射、源或外部剩余物质填零。

## 4. 标量场/EMS：独立静态解和不变量

保留既有成功 PG 结果，当前非 PG 只做球对称。球对称的原生3+1方程演化可以
成立，坐标和是否施加对称性是两项独立选择；此任务不增加完整非球对称三维演化要求。
报告应明确“施加球对称的非 PG 原生 BSSN/Z4c 演化”，不将其写为已验证全部
三维自由度。

在同一作用量、耦合、归一化、边界条件和静态分支上，补独立静态边值解或可追溯
文献数据；比较标量荷、面积视界半径 sqrt(A/4π)、视界标量幅度、ADM/电荷和
辐射/吸积引起的能量变化。跨坐标比较先转为面积半径及明确定义的不变量。
标量荷先核对场是否无质量、渐近边界及复场相位，不能自动套用1/r拟合。
文献图像数字化值应附数字化误差，不能按作者原始数据的精度引用。
当前[复现论文](https://arxiv.org/abs/2409.13184)与独立静态解的逐项核对仍待完成。
