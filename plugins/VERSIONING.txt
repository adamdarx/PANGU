Plugin release convention

Plugins whose documented implementation and interfaces have completed their
applicable verification are released as 1.0.0. In-development functionality is
not labelled stable merely because it compiles or because a scheduler job exits
successfully. Experimental/unimplemented capabilities are identified explicitly.

As of 2026-11-02 the documented releases are:
  diffusion            1.0.0
  electron             1.0.0
  ohmic                1.0.0
  radiation_cooling    1.0.0
  radiation_transport  1.0.0
  scalar_field         1.0.0
  viscosity            1.0.0

The plugin API version is independently versioned (currently API 1).
Physics benchmark acceptance and software interface release are recorded
separately: a stable interface does not make an unfinished production test
accepted or enlarge the documented physical scope.
